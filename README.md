# Multi-Restaurant Online Food Ordering System

A full-stack food ordering platform built with React and Spring Boot.

## Features
- 4 roles: Admin, Restaurant, Customer, Delivery
- JWT-based authentication
- Role-based access control
- REST APIs with Spring Security

## Tech Stack
**Frontend:** React, JavaScript, CSS  
**Backend:** Java, Spring Boot, Spring Security  
**Database:** MySQL  

## Setup

### Backend
```bash
cd foodapp
./mvnw spring-boot:run
```

### Frontend
```bash
npm install
npm start
```
